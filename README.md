# El Progreso

Sitio académico de una finca ganadera familiar. El proyecto usa HTML, CSS y JavaScript sin dependencias ni compilación.

- `index.html` contiene las secciones y la estructura semántica.
- `css/estilos.css` controla el diseño, la adaptación a pantallas pequeñas y los efectos visuales.
- `js/app.js` contiene los catálogos y controla el menú, la galería y el contacto simulado.
- `assets/` contiene fotografías WebP ilustrativas.

Abre `index.html` o sirve esta carpeta con un servidor HTTP estático. Google Maps necesita conexión a Internet. El mapa señala La Vega como ubicación de referencia. Los precios, el horario y los medios de contacto son ejemplos para la actividad.

Para publicar, crea un repositorio público de GitHub y sube con Git el contenido de esta carpeta a la rama `main`. En **Settings → Pages**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/ (root)`. GitHub mostrará el enlace cuando termine el despliegue. La guía oficial está en https://docs.github.com/es/pages/getting-started-with-github-pages/creating-a-github-pages-site .
